# 📚 Object-Oriented Stack Design Using C++ Templates

A menu-driven **Stack Application** developed in **C++** using **Class Templates**. This project demonstrates stack operations for multiple data types through a single generic implementation, along with menu-driven programming, object-oriented design, and colorful console output.

---

# ✨ Features

- Generic Stack implementation using **Class Templates**
- Menu-driven interface
- Supports multiple data types:
  - Integer
  - Character
  - Float
  - Double
  - String
- Push Operation
- Pop Operation
- Display Stack
- Stack Overflow Detection
- Stack Underflow Detection
- Empty Stack Detection
- Continue with Existing Stack
- Create New Stack
- Colored Console Output
- Input Validation with Limited Attempts
